# Native-speaker review queue

Content in `content/` was drafted without a native review. Before v1.0 every unit needs sign-off
from a German native teacher and, for every Swiss lane, a Zurich German native (Bernese forms from
a Bernese speaker). Sign-off is recorded in each unit's `review` field (`de`, `ch`, `date`); the open
questions for the reviewer are in `review.notes`. No unit has a human sign-off yet.

**Nothing on this page is a native review.** The AI passes catch clear errors and record the reasoning
and the sources, so the human reviewer can work faster. Every line still needs a native tick.

Legend: ✅ confirmed, no change · ✏️ corrected in content · ❓ no source found, still open

## Still for a human native speaker

1. **German native teacher:** every unit 1–6 (Standard German), especially the new grammar
   explanations (stem-changing verbs, separable verbs, telling the time, nicht/kein, doch, es gibt,
   location chunks) and the readings.
2. **Zurich native:** every ✏️, ✅ and ❓ line above as a tick list; the six Swiss-lane dialogues;
   these open forms:
   - clock times with `am` (`am sächsi`, `am Viertel ab sibni`, `bis am halbi achti`);
   - `ich stah uf` vs `ich stand uf`, and the person forms of `ufstah`, `ässe`, `läse`;
   - `kei` / `keis` / `käs`; `es git` vs `es hät`;
   - `du möchtsch / möchtisch`; `Waschchuchi`, `Huusornig`, `früe`.
3. **Bernese native:** every Bernese dialogue line listed above, and `vilech / villech`, `mir göh`,
   `i nime`, `ke / kei`, `wösche`.
4. **Audio scripts** once studio recording starts (v0.2). The audio scripts in `content/a1/unit-0N/`
   must be regenerated after these content changes (for example, Grossätti → Grosätti in unit 3).
