# Native-speaker review queue

Content in `content/` was drafted without a native review. Before v1.0 every unit needs sign-off
from a German native teacher and, for every Swiss lane, a Zurich German native (Bernese forms from
a Bernese speaker). The drafting author flagged these forms as uncertain:

## Zurich German (gsw-zh)
- Possessives: `ire / iri / ires` (ihr), `öise / öisi / öises` (unser)
- Verbs: `ich gsee / gsehne`, `du möchtisch, mir möchted`, `söle / sölle`, `dörfe … mir dörfed`, `wele / welle`
- Plurals and genders: `Brüeder / Brueder` (vs `Brüedere`), `Chind` vs `Chinde`, gender of `Zmorge`,
  `es Kafi` (the café) vs `en Kafi` (the drink)
- `Suscht / Süscht no öppis?`, `zwei` as default (`zwee / zwo`), `zää / zäh / zä`, `nüün`
- `Ich hett gern` vs `Ich hett gärn`, `wohäre / wo ane`, `niemert / niemer`, `moll / momoll`
- `Täfeli / Zältli`, `Chacheli`, `tifig`, `Güselchübel`

## Bernese (gsw-be)
- `Wie geits Ech?`, `Dir / Ihr` as polite form, `vilech`, `mir göh`, `i nime`, `Grossätti`, `Ghüderchübu`

## Swiss Standard German (ch-std) labels
- `Kellner / Servicemitarbeiter`, `Merci vielmal` (spoken ch-std), `Knabe (official) / Bub`, `Hahnenwasser`

## Curriculum notes (docs/CURRICULUM.md)
- `Er hät gseit, er heg kei Ziit` (Zurich subjunctive)
- Baseldytsch description (`Kind / Kuchi` with k, `mir sinn`)

## Open format questions
- A1 units 1 and 3 use `transform` from `de` to `de` (du → Sie). The UI labels it "Rewrite in Hochdeutsch".
- Listening MCQs refer to the dialogues until studio audio exists (v0.2).
